# retrain — V2 Step 2.1b: CIFAR-10 retrain r2 (same architecture)

Adopted as the CIFAR-10 reference of record in Step 2.1c (DECISIONS D3, D9):
`net_config.NET_CONFIGS["cifar10"]` → `v2/model/frozen/cifar10_int8_r2/`. The Step 2.1
set (`frozen/cifar10_int8/`) is kept as `NET_CONFIGS["cifar10_r1"]` for the record.

Network, preprocessing and INT8 pipeline are the legacy ones, imported unchanged
(`cifar10.model.Cifar10Net`, `cifar10.preprocess.make_transform`,
`cifar10.int8_model.calibrate`, calibration on train[0:1024]). Epoch selection used
val = train[45000:50000] only; the test set was evaluated once, by `check_r2.py`.

Reproduce (repo root, `.venv`):

    PYTHONDONTWRITEBYTECODE=1 .venv/bin/python v2/model/retrain/train_cifar10_r2.py
    PYTHONDONTWRITEBYTECODE=1 .venv/bin/python v2/model/freeze_cifar10_int8.py \
        --ckpt v2/model/retrain/cifar10_fp32_r2.pt --out v2/model/frozen/cifar10_int8_r2
    PYTHONDONTWRITEBYTECODE=1 .venv/bin/python v2/model/retrain/check_r2.py

Artifacts: `cifar10_fp32_r2.pt` (+ `.sha256`, `_meta.json`), `v2/model/frozen/cifar10_int8_r2/`
(`quant_params.npz`, `manifest.json`, `SHA256SUMS`, `hw_requant.npz` at B=32).

The freeze defaults are r2 since Step 2.1c, so `--ckpt`/`--out` above are optional.
`check_r2.py` is run by `v2/scripts/regen_results.sh` (after the main result scripts).

Results (label: model):
- `v2/results/cifar10_retrain_log.csv` — per-epoch train loss / val accuracy. A training
  artifact tied to the checkpoint SHA256; not regenerable without retraining (D9).
- `cifar10_r2_accuracy.csv` (r1 vs r2, val + test), `cifar10_r2_summary.csv` (acceptance
  rule) — regenerated by `check_r2.py`. Requant equivalence and the final-layer check for r2
  are the cifar10 rows of `requant_equivalence.csv` / `final_layer_check.csv`.
