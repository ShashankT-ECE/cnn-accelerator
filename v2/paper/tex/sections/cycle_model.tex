\section{Cycle Model}\label{sec:model}
The array accepts one reduction index per cycle and has no stall cycles;
the stall counter reads 0 on every recorded board job. A layer's cost
therefore follows from its loop nest.
% src: hw_a2_a3_cycles.csv hw_stall_max 0 (10,000 images per net), hw_shapes.csv hw_stall 0 (300 jobs), hw_soak.csv stall_nonzero 0
With
$T = \ceil{OC/8} \cdot OH \cdot \ceil{OW/8}$ tiles of
$K = IC \cdot KH \cdot KW$ cycles each, and each tile's drain hidden under
the next tile,
\begin{align}
\mathit{LAYER\_CYC} &= T K + \cpipe, \label{eq:model}\\
\mathit{TOTAL\_CYC} &= \cstart + \textstyle\sum_{\text{layers}} \mathit{LAYER\_CYC},\nonumber
\end{align}
where $\cpipe = 29$ is the fill and flush latency of the token pipeline and
$\cstart = 3$ is the pipelined descriptor check. Both constants were derived
from the RTL's stage latencies and committed before any simulation of the
core; RTL simulation matched without correction.
% src: DECISIONS D10-8 (C_PIPE = 29, commit 1eb0873), D13 (C_START = 3, commit 04470fc)
For the two networks the model gives 16,436 and 104,247 cycles per image,
or 65.7 and 417.0\,$\mu$s at 250\,MHz.
% src: cycle_model.csv / tab_a3_cycles.tex Total; tab_a2_latency.tex 250 MHz row (65.74 / 416.99 us)

\textbf{PE utilization}, the one utilization metric we use, is useful MACs
divided by $64 \times \mathit{TOTAL\_CYC}$ (model): 39.6\,\% for LeNet-5 and
67.3\,\% for CIFAR-10. % src: utilization_model.csv total rows util_total 0.395968 / 0.673497
Partial 8-wide tiles cause the loss: layers with a $1{\times}1$ output use
one array row (at most 12.5\,\%), and 10-class final layers at most
7.8\,\%. This is the known output-stationary limit on small feature maps.
% src: utilization_model.csv spatial_bound (conv5 / conv3 1/8; fc2 / fc 10/128)

\textbf{Ablation (model).} Our earlier output-stationary schedule, which pays
a fill and a drain per accumulation pass, would take 1.83$\times$ and
2.16$\times$ the cycles of (\ref{eq:model}) for the same array work.
