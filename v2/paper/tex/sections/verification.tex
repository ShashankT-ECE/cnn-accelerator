\section{Verification Methodology}\label{sec:verif}
The claim is exactness, so every step is checked for equality, not
tolerance. Each stage is compared with the one before it, from the
floating-point reference through the integer requantization, golden and
cycle models, and RTL simulation to the KV260, and every result is written
to a CSV that the paper's tables are generated from.

\textbf{Requantization.} For every channel we compared the integer pipeline
with the float64 reference on every non-saturating accumulator value
(139.6M values), plus the saturation boundaries and seeded samples beyond
them: 486.6M values, 0 mismatches (model).
% src: requant_equivalence.csv B=32: values_checked_exact 139,644,640; + values_checked_saturated 347,001,388; mismatches 0
Rounding $M \cdot 2^s$ to the nearest integer was not enough: near-ties
flipped in 2 of 354 channels, which use an $m$ one LSB away.
% src: requant_equivalence.csv delta_from_rne -1 (lenet5 conv5 ch82, cifar10 conv3 ch57); 354 channels

\textbf{Full-dataset simulation.} The golden model matches the legacy INT8
reference on every intermediate tensor of all 10,000 test images per
network (model). The RTL, simulated on all 20,000 images, is bit-exact and
cycle-exact on every image (RTL simulation, Verilator, cross-validated
against Vivado xsim before each run).
% src: golden_crosscheck.csv; rtl_full10k.csv (10000/10000 bit- and cycle-exact per net); run_full10k.sh xval

\textbf{Random shapes and robustness.} A seeded generator produced 300
multi-layer jobs in 13 categories; all 286 legal jobs are bit- and
cycle-exact and all 14 illegal ones are refused (RTL simulation). Further
suites cover 11 unit testbenches, 100 random single-layer shapes, 255
checker cases, back-to-back jobs with a refused job and a mid-job soft
reset, and post-synthesis netlist simulation.
% src: shapes_rtl.csv / tab_shapes; tab_verification (11 unit TBs, fuzz 100, checker 255, netlist 2 + 3 jobs); unit_tb.csv tb_gos_top_backtoback (job count not in a CSV -> no number)

\textbf{What verification found.} Random shapes exposed a limit the checker
does not enforce: kernel widths of 10 or more give wrong outputs. We made
$KW \le 9$ a host-side contract, boundary-tested the descriptor fields in
49 cases on two simulators, and added host checks wherever the hardware
checker has a gap. % src: DECISIONS OC-3; limits_rtl.csv (49 rows, Verilator + xsim)

\textbf{Provenance.} Every number carries its git commit; rows from a dirty
tree are rejected, and board rows also carry the bitstream hash and the
hardware BUILD\_ID. % src: DECISIONS D16; paper/README.md
